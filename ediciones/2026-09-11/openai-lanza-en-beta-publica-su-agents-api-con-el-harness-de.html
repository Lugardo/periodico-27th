Agentic coding

OpenAI lanza en beta pública su Agents API, con el harness de Codex detrás

La API expone la misma infraestructura que sostiene a Codex: manejo de sesiones, orquestación de herramientas, sandboxes y recuperación ante fallos, para tareas que pueden tardar horas o días.

OpenAI abrió el 10 de septiembre la beta pública de su Agents API, que pone a disposición de cualquier desarrollador el mismo harness que impulsa a Codex. En lugar de que cada equipo tenga que construir su propia capa de orquestación, la API se encarga de preservar contexto entre pasos, ejecutar herramientas, gestionar archivos, recuperarse de interrupciones y coordinar subagentes que trabajan en paralelo durante sesiones largas.

El harness es de código abierto, lo que da visibilidad sobre la lógica que decide cuándo llamar al modelo, cuándo usar una herramienta y cómo se gestiona el contexto conforme crece la tarea. Para la ejecución de código y accesos a archivos, OpenAI ofrece un sandbox propio —el mismo que usan ChatGPT y Codex— además de integraciones de primera clase con proveedores externos como Cloudflare, Modal, E2B, Daytona, DigitalOcean, Oracle, Vercel, Runloop y Blaxel.

No hay cargos adicionales por usar la API: se paga únicamente por los tokens y las herramientas que el agente consuma. Es una apuesta directa a que la orquestación de agentes deje de ser un problema de infraestructura para cada empresa y pase a ser un servicio administrado, terreno donde compite con ofertas equivalentes de Anthropic y Google.
