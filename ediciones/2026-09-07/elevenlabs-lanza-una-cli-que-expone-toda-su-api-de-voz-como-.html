ElevenLabs lanza una CLI que expone toda su API de voz como comandos de terminal

Cada operación de la API de ElevenLabs ahora es un subcomando de la nueva CLI, pensada para manejar agentes de voz "como código": configuración en archivos, sincronización y pruebas automatizadas.

ElevenLabs publicó la versión 1.0 de su interfaz de línea de comandos, que expone cada operación de su API -voces, agentes conversacionales, doblaje, y demás- como un subcomando propio, con salida en JSON, tabla, YAML o CSV, paginación automática y autocompletado de shell. La apuesta central es tratar a los agentes de voz "como código": guardar la configuración de agentes, herramientas y pruebas en archivos versionables, sincronizarlos con comandos de push y pull, manejar ramas y correr tests desde la terminal.

En paralelo, ElevenLabs llevó a disponibilidad general las "procedures" dentro de ElevenAgents: bloques de instrucciones específicas para una tarea, con una condición que determina cuándo se activan. Esto permite que un mismo agente maneje varias tareas distintas sin amontonar todas las instrucciones posibles en un único system prompt gigante, algo que hasta ahora obligaba a elegir entre agentes muy especializados o prompts difíciles de mantener.

La compañía también sumó una API de "triage" de conversaciones: tickets automáticos sobre el desempeño de un agente, tickets de seguimiento manual, asignación a miembros del equipo y comentarios a nivel de ticket o de turno de conversación. En conjunto, son señales de que ElevenLabs apunta a equipos que operan agentes de voz en producción y necesitan las mismas herramientas de control de versiones, testing y triage que ya usan para código convencional.
