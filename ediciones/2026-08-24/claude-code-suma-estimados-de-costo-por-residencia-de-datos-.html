Claude Code suma estimados de costo por residencia de datos y un comando para migrar el SDK de Python

La versión 2.1.239 calcula el sobrecosto de la inferencia exclusiva en EE.UU., ofrece pantalla completa en Bedrock, Vertex y Foundry, y trae /claude-api upgrade para saltar del SDK de Python 0.x a la 1.x.

Anthropic siguió con su cadencia casi diaria de actualizaciones de Claude Code. La versión 2.1.239, publicada el 21 de agosto, agrega estimados del costo adicional que implica exigir inferencia solo en territorio estadounidense para workspaces con requisitos de residencia de datos; ese cálculo ahora aparece en el comando /cost, en la barra de estado y en el flag --max-budget-usd, lo que facilita presupuestar antes de activar esa restricción.

La misma versión extiende por primera vez el modo de renderizado en pantalla completa a configuraciones que antes quedaban fuera, como Bedrock, Vertex AI, Microsoft Foundry y otros despliegues empresariales, ofreciéndolo como una opción puntual dentro de la sesión. También se suma /claude-api upgrade, un comando pensado para equipos que todavía usan la versión 0.x del SDK de Python de Anthropic y quieren migrar a la 1.x sin revisar manualmente cada llamada rota.

Las dos versiones siguientes, 2.1.240 y 2.1.241, publicadas el 22 y 23 de agosto respectivamente, se centraron en corrección de errores y estabilidad general, sin features nuevas destacadas, lo que sugiere que el equipo está puliendo antes de un salto de versión mayor.
