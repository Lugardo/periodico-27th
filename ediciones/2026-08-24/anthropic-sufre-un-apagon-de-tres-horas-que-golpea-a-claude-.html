Infraestructura

Anthropic sufre un apagón de tres horas que golpea a Claude Code y la API

Claude.ai, la API, Claude Code y Cowork registraron errores elevados durante la madrugada del 24 de agosto; Anthropic resolvió el incidente en poco más de tres horas.

Poco después de la medianoche en la costa este de Estados Unidos, usuarios de Claude empezaron a reportar fallos de acceso. Anthropic confirmó el problema en su página de estado a las 5:06 UTC y lo marcó como identificado apenas veintiún minutos después. Los modelos Claude Mythos 5, Claude Fable 5, Claude Opus 5 y Claude Opus 4.8 fueron los más afectados, con errores elevados que golpearon simultáneamente a claude.ai, la API en api.anthropic.com, Claude Code y Claude Cowork. La consola de desarrolladores y Claude for Government siguieron funcionando con normalidad durante todo el incidente.

El servicio quedó restablecido hacia las 8:30 UTC, unas tres horas después del primer reporte, aunque Anthropic no ha detallado públicamente la causa raíz ni el volumen de solicitudes que fallaron. Para equipos que corren pipelines de CI o agentes en producción sobre la API de Claude, el episodio es un recordatorio de que vale la pena tener manejo de reintentos y, si el presupuesto lo permite, un modelo de respaldo en otro proveedor.

No es un hecho aislado: el estado de Anthropic ha registrado más de una decena de incidentes solo en lo que va de agosto, varios de ellos afectando a los mismos modelos de la familia 5. La compañía atraviesa además una fase de crecimiento acelerado de infraestructura, con acuerdos de cómputo multimillonarios anunciados este mismo mes, lo que hace pensar que parte de esta inestabilidad podría estar ligada a la expansión de capacidad.
