Agentic coding

GitHub Copilot estrena Agent Merge para llevar un pull request hasta el merge sin intervención

La función, en vista previa pública dentro de VS Code 1.136, resuelve conflictos, corrige checks de CI que fallan y atiende comentarios de revisión de forma autónoma hasta que el pull request queda listo para fusionarse.

GitHub llevó a vista previa pública Agent Merge, una función de Copilot que toma un pull request y lo acompaña durante el resto de su ciclo de vida: monitorea la integración continua, da seguimiento a los revisores requeridos y corrige los checks que fallan. El desarrollador decide hasta dónde debe llegar el agente —solo devolver la CI a verde, atender comentarios de revisión, o fusionar directamente cuando se cumplen ciertas condiciones—, y la función se activa por sesión desde la ventana de Agents o con el ajuste chat.agentMerge.enabled.

La función llega junto con otros cambios que refuerzan el giro de Copilot hacia un producto "agent-native": los espacios de trabajo multi-raíz, todavía experimentales, ahora llevan sesiones de agentes de Copilot y de Claude a cada carpeta abierta en el editor.

Para equipos que ya delegan la escritura de código a agentes, Agent Merge apunta al tramo que sigue quedando manual: sostener un pull request vivo mientras pasa por revisiones humanas, checks automatizados y conflictos de fusión, sin que un desarrollador tenga que ir empujándolo paso a paso.
