Claude Code 2.1.332 permite que los servidores MCP distribuyan skills

La versión publicada hoy agrega, en beta, skills servidas desde servidores MCP y un nuevo hook para vetar comandos de shell que una skill intente ejecutar al cargarse.

Anthropic liberó Claude Code 2.1.332 con una novedad de fondo para quien construye integraciones: los servidores MCP ya pueden entregar skills, no solo herramientas. En el menú `/` aparecen con el formato `servidor:skill`, de modo que un mismo servidor puede empaquetar el acceso a un sistema y las instrucciones procedimentales para usarlo bien. La función está en beta.

Como contrapeso de seguridad llega el evento de hook `PreSkillShellCommand`, que permite rechazar los comandos de shell en línea que una skill o comando intente correr al cargarse. Es la pieza que faltaba para que los equipos acepten skills de terceros sin abrir la puerta a ejecución arbitraria. La release también corrige que los IDs de tareas MCP de más de 128 caracteres fallaran (ahora se aceptan hasta 1,024).

En el frente de proveedores, el alias `sonnet` en Google Cloud Agent Platform y Microsoft Foundry pasa a apuntar a Sonnet 5.5, Foundry adopta Opus 5.5 para `opus` y Sonnet 5.5 como modelo por defecto, y Sonnet 4, Opus 4 y Opus 4.1 quedan marcados como retirados en Foundry. Si tienes filtros de OpenTelemetry basados en `service.name`, revisa: las sesiones de la pestaña Code de Desktop ahora reportan `claude-code-desktop`.
