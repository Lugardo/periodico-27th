Google renueva los Managed Agents de la API de Gemini con el harness de Antigravity

La versión antigravity-preview-09-2026 lleva las herramientas y el comportamiento del agente de código Antigravity a AI Studio y a la Interactions API, con nuevas APIs de archivos y credenciales.

Google actualizó los Managed Agents de la API de Gemini para acercar su comportamiento al del agente de codificación Antigravity. La nueva versión, identificada como antigravity-preview-09-2026, corre sobre Gemini 3.8 Flash —configurable por interacción— y da acceso, con una sola llamada de API, a un agente que razona, ejecuta código, administra archivos y navega la web dentro de un sandbox de Linux alojado por Google.

A diferencia de una petición de chat convencional que devuelve una sola respuesta, cada interacción con estos agentes gestionados dispara un ciclo autónomo de razonamiento, ejecución de herramientas, corridas de código y manejo de archivos. La actualización suma dos piezas nuevas: una Files API para mover datos dentro y fuera del entorno del agente, y una Credentials API para que el agente use servicios de servidores MCP y APIs de terceros de forma segura, sin exponer directamente las credenciales al modelo.

El precio sigue un esquema de pago por uso basado en los tokens del modelo subyacente y en las herramientas que el agente utilice durante cada interacción, disponible tanto en el nivel gratuito como en el de pago.
