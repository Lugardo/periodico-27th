GitHub Copilot CLI suma a GPT-6 Astra y Claude Fable 5.1 en una tanda rápida de releases

En apenas dos días, GitHub publicó varias versiones de Copilot CLI que agregan soporte para los modelos más nuevos de OpenAI y Anthropic, refuerzan el aislamiento de los comandos en sandbox e integran la herramienta con la barra de tareas de Windows 11.

GitHub encadenó varias actualizaciones de Copilot CLI el 3 y 4 de septiembre. La v1.0.83, marcada como la última release estable, agrega soporte para claude-fable-5.1, inicio de sesión OAuth para servidores MCP, integración con la barra de tareas de Windows 11 (con tarjetas de estado al pasar el cursor sobre una sesión activa) y mejoras de sandboxing con restricciones de salida de red. Un día después, la v1.0.84-1 sumó soporte para gpt-6-astra.

Los cambios de seguridad son notables para quien corre la CLI en Linux: el sandbox ahora restringe el tráfico de salida al proxy configurado y exige slirp4netns, una versión reciente de util-linux, iptables y acceso a /dev/net/tun. Además, ahora es posible definir un agente personalizado con una lista de varios modelos que la CLI prueba en orden hasta encontrar uno disponible para la cuenta del usuario, con una política que puede forzar que solo se use esa lista.

Para equipos que dependen de Copilot CLI en flujos agentic, la actualización significa acceso casi inmediato a los modelos insignia de OpenAI y Anthropic apenas se liberan, junto con un aislamiento más estricto de lo que esos agentes pueden tocar en la red del equipo de desarrollo.
