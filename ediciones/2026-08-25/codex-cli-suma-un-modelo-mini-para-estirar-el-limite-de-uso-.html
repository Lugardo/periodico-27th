Codex CLI suma un modelo mini para estirar el límite de uso de ChatGPT

OpenAI añadió GPT-5-Codex-Mini a Codex CLI y a su extensión de IDE, una versión más liviana pensada para subagentes y exploración que multiplica por cuatro el uso incluido en el plan.

OpenAI incorporó GPT-5-Codex-Mini como opción de modelo dentro de Codex CLI y de la extensión de IDE de Codex. Se trata de una versión reducida y más económica de GPT-5-Codex, pensada para tareas de exploración de código y para correr como subagente dentro de una sesión más grande, donde no hace falta la capacidad completa del modelo principal.

Para cuentas de ChatGPT Plus, Edu y Team, el modelo mini rinde hasta cuatro veces más uso dentro de la misma cuota que GPT-5-Codex, y Codex ofrece automáticamente el cambio a la versión mini cuando una sesión llega al 90% del límite de cinco horas, evitando que el trabajo se corte de golpe.

El ajuste es parte de un patrón más amplio en Codex durante el mes: mejoras al panel interactivo de agentes, nuevos comandos para manejar directorios de trabajo, mensajería en cola para sesiones existentes y diagnósticos más completos vía codex doctor, todo apuntando a hacer más manejables las sesiones largas de agente en lugar de sumar capacidad de modelo.
