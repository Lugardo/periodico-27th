Agentic coding

GitHub lleva las sesiones de agente de Copilot a Microsoft Teams

GitHub habilitó sesiones de Copilot en la nube dentro de canales de Teams, donde cualquiera en la conversación puede sumar contexto y quien tenga permisos de escritura puede disparar cambios en el repositorio.

GitHub sumó a Copilot la posibilidad de arrancar y seguir sesiones de agente en la nube directamente desde un canal, hilo o mensaje directo de Microsoft Teams, mencionando a @GitHub. La sesión queda visible para todo el equipo dentro de esa conversación: cualquier persona puede hacer preguntas, aportar contexto o ayudar a planear el trabajo, aunque solo quienes tienen permiso de escritura sobre el repositorio pueden pedirle a Copilot que aplique cambios reales.

La idea apunta a bajar la fricción entre discutir una tarea y ejecutarla: en lugar de copiar contexto desde Teams hacia un editor o hacia el sitio de GitHub, el agente queda instanciado en el mismo hilo donde ya se está hablando del problema, y el resultado del trabajo —incluyendo decisiones intermedias— queda documentado ahí mismo para el resto del equipo.

El anuncio se suma a otros ajustes recientes en el ecosistema Copilot, como soporte de nivel de esfuerzo de razonamiento más alto en la CLI para modelos de terceros y correcciones en el manejo de plugins y skills.
