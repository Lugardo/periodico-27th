AWS amplía la búsqueda web para agentes de Bedrock AgentCore a Europa y Asia-Pacífico

Amazon sumó filtros por dominio y fecha de publicación a la herramienta de búsqueda web de Bedrock AgentCore, y la expandió más allá de Estados Unidos.

AWS actualizó Web Search, la herramienta gestionada de Bedrock AgentCore que permite a los agentes obtener conocimiento web actual y citado sin que los datos salgan de la cuenta de AWS del cliente. La novedad de este mes agrega control por solicitud sobre qué dominios se consultan y en qué ventana de tiempo, además de sumar disponibilidad en las regiones de Europa (Irlanda) y Asia-Pacífico (Tokio), que se suman a la región original en el este de Estados Unidos.

La herramienta funciona como un conector integrado en Bedrock AgentCore Gateway, expuesto vía Model Context Protocol: el agente envía una consulta en lenguaje natural y recibe fragmentos relevantes junto con URLs de origen, títulos y fechas de publicación, sin necesidad de que el equipo de desarrollo mantenga su propia integración con un proveedor de búsqueda externo.

Para equipos que operan bajo restricciones de residencia de datos en Europa o Asia, la expansión regional resuelve un bloqueo práctico que antes obligaba a enrutar el tráfico de búsqueda a través de Estados Unidos o a construir una alternativa propia.
