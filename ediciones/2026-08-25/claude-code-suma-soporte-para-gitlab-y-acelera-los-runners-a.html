Agentic coding

Claude Code suma soporte para GitLab y acelera los runners autohospedados

Las versiones recientes de Claude Code añadieron integración con merge requests de GitLab, arranques más rápidos de runners self-hosted y validaciones más estrictas de gateways y plugins.

El changelog reciente de Claude Code incorpora soporte para merge requests de GitLab —hasta ahora el flujo de revisión estaba centrado en GitHub—, lo que abre la herramienta a equipos que operan su control de versiones fuera del ecosistema de Microsoft. Junto con eso, Anthropic reporta tiempos de arranque más rápidos para runners autohospedados, un punto de fricción habitual cuando se corren agentes en infraestructura propia en lugar de la nube gestionada.

Las versiones también refuerzan la validación de gateways y de plugins de terceros, además de mejoras de accesibilidad y de diagnóstico, y varias correcciones puntuales en Linux, Windows, en el manejo de MCP y en la gestión de permisos y sesiones.

Son ajustes de fricción diaria más que anuncios de capacidad nueva, pero para equipos que ya corren Claude Code como agente de coding en su pipeline, reducen fricción real en los dos puntos donde más se nota: integrarlo con el sistema de control de versiones que usan y mantenerlo estable en runners propios.
