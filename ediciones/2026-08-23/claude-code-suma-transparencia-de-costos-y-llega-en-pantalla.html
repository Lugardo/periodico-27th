Claude Code suma transparencia de costos y llega en pantalla completa a Bedrock, Vertex y Foundry

La actualización del 22 de agosto añade el recargo por inferencia exclusiva en EE. UU. a las estimaciones de costo, extiende el modo de pantalla completa a más nubes y suma un asistente de migración a la API 1.x en Python.

Anthropic publicó una nueva actualización de Claude Code que hace más transparentes las estimaciones de costo: el comando /cost, la barra de estado y la bandera --max-budget-usd ahora incluyen el recargo de 1.1x que aplica a la inferencia exclusiva en Estados Unidos para espacios de trabajo con residencia de datos.

La actualización también extiende la oferta de renderizado en pantalla completa a configuraciones que antes quedaban excluidas, como Bedrock, Vertex AI y Azure AI Foundry: las instalaciones nuevas en esos entornos ahora arrancan directamente en ese modo. Se agregó además el comando /claude-api upgrade, pensado para ayudar a proyectos en Python a migrar del SDK 0.x al 1.x de Anthropic, junto con soporte nativo para pegar imágenes, portapapeles y captura de audio en builds sobre Alpine/musl.

Por el lado de las sesiones en la nube, los plugins sincronizados desde claude.ai ahora se identifican como nombre@synced, son compatibles con claude plugin enable/disable y nunca sobrescriben un plugin instalado localmente con el mismo nombre, lo que reduce el riesgo de conflictos para equipos que combinan configuración local y en la nube.
