Managed Agents de Anthropic gana presupuestos de sesión, modelos asesores y skills desde GitHub

La plataforma para desarrolladores de Claude suma controles de gobierno para agentes en producción, mientras el directorio de conectores MCP supera los 950 servidores.

Anthropic amplió los controles disponibles para Claude Managed Agents en su Developer Platform. Ahora es posible fijar un presupuesto de gasto duro por sesión: al alcanzarlo, la sesión se pausa con el motivo budget_reached en lugar de seguir generando solicitudes al modelo, y se reanuda si el presupuesto se modifica o se elimina.

También se puede asignar un modelo "asesor" a la sesión de un agente: un modelo al menos tan capaz como el principal, al que el hilo primario puede consultar a media tarea para pedir orientación estratégica, configurándolo como una entrada de tipo advisor dentro del roster multiagente. A esto se suma el control de dónde corre físicamente la inferencia (inference_geo), configurable por agente o por sesión individual, y la posibilidad de que un agente cargue skills directamente desde un repositorio de GitHub montado en la sesión.

En paralelo, el directorio de conectores MCP de Claude superó los 950 servidores listados, usados según la compañía por millones de personas cada día. En conjunto, estas piezas apuntan a equipos que ya corren agentes de Claude en producción y necesitan más gobierno sobre costo, capacidad, residencia de datos y qué herramientas puede tocar cada agente.
