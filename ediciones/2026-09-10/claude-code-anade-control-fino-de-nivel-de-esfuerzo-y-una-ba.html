Agentic coding

Claude Code añade control fino de nivel de esfuerzo y una bandera para el system prompt

La actualización permite limitar el 'effort level' por proveedor o por modelo, y ofrece una opción para regenerar el system prompt en cada solicitud en lugar de reutilizar el de la conversación.

Anthropic sumó a Claude Code una configuración maxEffortLevel, definible de forma global o por modelo dentro de modelSettings, que limita el nivel de esfuerzo de razonamiento que puede usar el modelo sin importar el proveedor de nube que se use —incluidos Bedrock, Vertex AI y Foundry—, aunque los usuarios conservan la posibilidad de elegir un nivel más bajo si así lo prefieren. Es una forma directa de controlar costo y latencia en equipos que ejecutan Claude Code a escala.

La actualización también incorpora la bandera --system-prompt-snapshot off, que hace que el system prompt se genere de nuevo en cada solicitud en lugar de reutilizar el que quedó registrado al inicio de la conversación, algo útil en sesiones largas donde las instrucciones base del sistema pueden haber cambiado.

El resto de la versión se concentra en corrección de fallos: tareas programadas de Cowork que fallaban al iniciar en organizaciones con sandboxing obligatorio, salida en blanco de /context y otros comandos locales en clientes móviles, atajos de teclado que dejaban de responder tras reconectar una sesión de tmux o SSH dentro de una vista de agente, y un encabezado del último prompt que no aparecía correctamente al desplazarse hacia arriba en modo de pantalla completa.
