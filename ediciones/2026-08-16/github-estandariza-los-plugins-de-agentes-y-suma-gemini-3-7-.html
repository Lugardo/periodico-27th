GitHub estandariza los plugins de agentes y suma Gemini 3.7 Flash y Grok 4.6 a Copilot

Junto con AWS, Cursor, Microsoft, OpenAI y Google, GitHub publica Agent Plugins 1.0, un formato abierto para empaquetar skills y servidores MCP que funciona en cualquier cliente compatible.

GitHub publicó, junto con AWS, Anysphere (la empresa detrás de Cursor), Microsoft y OpenAI como impulsores iniciales, y con Google sumándose el mismo día como mantenedor central, la especificación Agent Plugins 1.0. Es un estándar abierto y neutral que empaqueta Agent Skills y servidores MCP en un solo plugin distribuible que cualquier cliente de agentes compatible puede descubrir e instalar. La idea es terminar con la duplicación de trabajo que suponía empaquetar el mismo plugin de forma distinta para cada proveedor.

El soporte ya está disponible en general en VS Code, Copilot CLI, el SDK de GitHub Copilot y la app de Copilot, en todos los planes. Los plugins existentes que no apuntan a la versión 1.0 siguen funcionando sin necesidad de migrar.

En paralelo, Copilot amplió su catálogo de modelos: Gemini 3.7 Flash y Grok 4.6 de xAI ya están disponibles como opción dentro de chat y modo agente, además del modelo propio de GitHub, MAI-Code-1.1-Flash (su predecesor, MAI-Code-1-Flash, se retira el 10 de septiembre). Copilot para JetBrains también sumó memoria persistente entre sesiones de chat con agentes y acceso a modelos locales vía Ollama.
