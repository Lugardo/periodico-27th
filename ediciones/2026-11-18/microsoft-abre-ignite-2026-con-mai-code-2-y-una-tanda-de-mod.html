Microsoft abre Ignite 2026 con MAI Code 2 y una tanda de modelos propios para competir en precio

MAI Code 2 y MAI Code 2 Flash ya están disponibles en GitHub; Microsoft afirma que el primero logra 98% del rendimiento de GPT-6.1 Sol al 40% del costo.

En el primer día de Ignite, Microsoft presentó varios modelos de primera parte con los que busca restarle terreno a OpenAI y Anthropic en el segmento empresarial. Los protagonistas para desarrolladores son MAI-Code-2, orientado a trabajo agentic de programación exigente, y MAI-Code-2-Flash, para el volumen diario de tareas de código más ligeras.

Ambos están disponibles de forma general en GitHub Copilot, mientras que la versión Flash entra en preview de acceso limitado en Foundry. Microsoft sostiene que MAI Code 2 entrega 98% del desempeño de GPT-6.1 Sol al 40% del precio en benchmarks de código empresarial; son cifras del propio fabricante, aún sin validación independiente. GitHub también anunció que MAI-Code-1.1-Flash será retirado en diciembre.

La tanda incluye además MAI Cyber 2 Flash para seguridad y Microsoft-Decision-1.1, ya disponible de forma general en Foundry. Del lado de la plataforma, Foundry suma un router de modelos en Foundry Models y, en preview, despliegue a clústeres AKS del cliente, Agent Grid y sandboxes para agentes.
