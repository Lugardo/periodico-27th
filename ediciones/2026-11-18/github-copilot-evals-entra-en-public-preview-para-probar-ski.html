GitHub Copilot Evals entra en public preview para probar skills, agentes y herramientas MCP

La nueva función permite correr evaluaciones contra skills, custom agents y MCP tools para detectar regresiones; está disponible en los planes Individual, Business y Enterprise.

GitHub publicó el 17 de noviembre Copilot Evals en public preview. La idea es dar a los equipos una manera estándar de evaluar las piezas con las que extienden Copilot —skills, custom agents y herramientas expuestas vía MCP— y ver de un vistazo qué casos pasan y cuáles fallan cuando algo cambia.

Según reportes secundarios, el motor de evaluación es Vally, una herramienta local que se instala como extensión de VS Code, plugin de Copilot CLI o desde la app de GitHub Copilot. Los flujos desde la CLI requieren el modo experimental, y GitHub no ha dado fecha para la disponibilidad general.

Para quien mantiene agentes o servidores MCP en producción, esto acerca las prácticas de testing de software a la capa de prompts y herramientas, donde hasta ahora las regresiones solían descubrirse a mano.
