Codex CLI 0.169.0: pestañas de side chats, búsqueda de tareas y un `codex exec` más estricto con la confianza

La nueva versión del agente de terminal de OpenAI suma varias pestañas de chat lateral, búsqueda en el centro de tareas y un flag --trust explícito para ejecuciones en directorios no confiables.

OpenAI publicó Codex CLI 0.169.0, ya marcada como latest en npm. El workspace de terminal opcional ahora admite varias pestañas de side chat, navegables con teclado o mouse, y los side chats locales guardados se pueden reabrir tras reiniciar. En el agent command center se pueden buscar tareas antiguas por nombre, vista previa del prompt o directorio de trabajo.

Los model providers personalizados se pueden añadir o editar desde la terminal, incluso durante el inicio de sesión, con un flujo de device code para sesiones SSH o máquinas sin navegador. El transcript a pantalla completa gana la opción Collapse turn details, que pliega la actividad de herramientas ya terminada sin ocultar las respuestas.

El cambio con más impacto operativo es de seguridad: en directorios no confiables, `codex exec` mantiene desactivados la configuración del proyecto y los servidores MCP aunque se use `--sandbox workspace-write`. Para guardar la confianza hay que pasar `--trust` de forma explícita a `codex exec` o `codex review`, algo a revisar en scripts de CI que dependían del comportamiento anterior.
