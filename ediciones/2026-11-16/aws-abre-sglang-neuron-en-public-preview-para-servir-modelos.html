AWS abre SGLang-Neuron en public preview para servir modelos en Trainium con la API de SGLang

Un plugin out-of-tree con licencia Apache 2.0 permite correr el servidor de SGLang sobre chips Trainium cambiando una variable de entorno.

AWS hizo público SGLang-Neuron, que llega como v0.1.0 en public preview y con licencia Apache 2.0, después de una beta cerrada en octubre. Se trata de un plugin out-of-tree: SGLang conserva su servidor de API y el scheduling de peticiones, mientras la ejecución del modelo pasa por PyTorch nativo sobre Neuron. Se activa al arrancar el servidor con `SGLANG_PLATFORM=neuron` y también está disponible en un AWS Deep Learning Container.

El soporte inicial incluye modelos densos de razonamiento, variantes de Llama, arquitecturas MoE estilo DeepSeek, GLM, Kimi y GPT-OSS 120B. La cobertura de lanzamiento menciona despliegues de Kimi K3 desagregados en tres nodos y GLM-5.2 con contexto de 1M.

Para equipos que ya sirven con SGLang en GPU, la promesa es mover cargas a Trainium sin cambiar de API. Conviene tomarlo como preview: los ejemplos publicados por AWS muestran configuraciones de referencia, no benchmarks, y el trabajo de rendimiento sigue en curso.
