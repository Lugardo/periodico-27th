Agentic coding

Claude Code suma mensajería entre sesiones y un modo restringido para entornos sensibles

La nueva versión permite que distintas sesiones de Claude Code se envíen mensajes entre sí y añade un modo `--restricted` que bloquea herramientas de ejecución de código para correrlo en contextos donde la seguridad es prioritaria.

Anthropic actualizó Claude Code con dos funciones pensadas para flujos de trabajo con múltiples agentes. La primera, mensajería entre sesiones, permite que una sesión de Claude Code envíe mensajes a otra sesión activa mediante nuevas capacidades internas de comunicación, lo que facilita coordinar tareas entre agentes que trabajan en paralelo sobre distintas partes de un mismo proyecto. Cuando el buzón de una sesión rechaza un mensaje —por límite de tasa o cola llena— la sesión que lo envió ahora recibe una notificación en lugar de que el mensaje simplemente se pierda. Esta función no está disponible todavía en despliegues sobre Amazon Bedrock, AWS, Google Cloud Agent Platform o Microsoft Foundry.

La segunda novedad es un modo restringido, activable con la bandera `--restricted` o la variable de entorno correspondiente, que elimina las herramientas integradas capaces de ejecutar comandos o código arbitrario y deshabilita el acceso web, mantiene las herramientas de archivos confinadas al directorio de trabajo, rechaza el modo `bypassPermissions` e ignora archivos de configuración de usuario, proyecto o locales. Está pensado para correr el agente en entornos donde una ejecución de comandos no autorizada representaría un riesgo inaceptable.

La actualización también incluye créditos de uso para organizaciones Enterprise, mejores diagnósticos cuando la configuración es administrada por un servidor central, y una serie de correcciones en runners autoalojados, flujos de login y manejo de terminal. En conjunto, el paquete refleja que Anthropic está optimizando Claude Code tanto para escenarios de múltiples agentes coordinados como para despliegues corporativos con requisitos estrictos de seguridad.
