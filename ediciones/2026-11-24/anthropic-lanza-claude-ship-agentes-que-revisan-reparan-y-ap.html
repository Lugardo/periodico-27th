Agentic coding

Anthropic lanza Claude Ship: agentes que revisan, reparan y aprueban pull requests en GitHub

Claude Ship agrupa tres agentes para el ciclo de PRs: Code Review (ya disponible de forma general), PR Steward y Claude Approvals, estos dos últimos en beta para clientes Team y Enterprise.

Anthropic presentó el 23 de noviembre Claude Ship, un paquete de agentes pensado para el tramo final del desarrollo: el que va desde que se abre un pull request hasta que se fusiona. Incluye tres piezas. Code Review, que ya existía y ahora figura como disponible de forma general, analiza los cambios con varios agentes y ordena los hallazgos por severidad. PR Steward se encarga de mantener el PR en buen estado: resuelve conflictos de merge, corrige checks de CI que fallan y deja un comentario explicando qué modificó, pero no aprueba ni fusiona.

La novedad más delicada es Claude Approvals, que puede dar el visto bueno a cambios rutinarios siempre dentro de los límites que defina la política de cada equipo. Según la cobertura, Anthropic recomienda arrancar en modo de solo observación antes de dejar que el agente apruebe de verdad. Los agentes de revisión y PR Steward corren en la nube de Anthropic, mientras que desde Claude Code se puede invocar el flujo localmente con el comando /ship; los administradores también pueden activarlos para un repositorio completo.

Anthropic compartió cifras internas: en el equipo de Claude Code, los PRs fusionados se duplicaron con creces entre junio y septiembre de 2026 y la proporción de PRs revertidos bajó más de 40%. Son datos reportados por la propia empresa, y ella misma aclara que la revisión de Claude es solo una capa dentro de un proceso más amplio. Para equipos que ya generan mucho código con agentes, el cuello de botella se está moviendo de escribir a revisar, y este lanzamiento apunta justo ahí.
