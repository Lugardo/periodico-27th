Microsoft documenta cómo grupos estatales usan ARTEX, un framework agéntico de pentesting, para acelerar ataques

Microsoft Threat Intelligence vincula a seis actores, entre ellos Salt Typhoon y Onyx Sleet, con el uso de esta herramienta open source y publica guía de detección para defensores.

Microsoft Threat Intelligence publicó una guía sobre ARTEX, un framework open source de pentesting impulsado por IA que apareció en GitHub en julio de 2026. Según la empresa, actores como Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon y Salt Typhoon, tanto patrocinados por estados como con fines económicos, lo han incorporado para automatizar reconocimiento de red, ataques de credenciales y explotación de aplicaciones web.

Microsoft subraya que ARTEX no trae técnicas nuevas: orquesta herramientas de pentesting conocidas y prueba un enfoque tras otro a velocidad de máquina. Lo que cambia es el ritmo, ya que puede pasar del escaneo a acceso privilegiado persistente en minutos según las defensas del objetivo, y los operadores rotan IPs y user agents para evadir detección por firmas. En publicaciones previas, la empresa ya había descrito su uso para buscar secretos OAuth expuestos en GitHub y en una campaña de cadena de suministro.

Las recomendaciones incluyen reducir la superficie expuesta a internet empezando por un inventario externo, configurar políticas de riesgo en Entra ID y activar reglas analíticas de Sentinel que detectan este patrón de actividad. Para equipos de desarrollo, el recordatorio práctico es no dejar secretos en repositorios y revisar qué servicios quedan públicos.
