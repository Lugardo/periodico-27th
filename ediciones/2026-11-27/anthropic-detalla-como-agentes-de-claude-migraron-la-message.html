Agentic coding

Anthropic detalla cómo agentes de Claude migraron la Messages API de Python a Rust sin apagar el servicio

El equipo reescribió por completo el servicio que atiende cada petición a Claude; el resultado usa cerca de 70% menos CPU y más de 80% menos memoria por petición, con un time to first token ~20% menor.

Anthropic publicó en su blog de ingeniería el recuento de la migración de su Messages API, el servicio construido en Python en 2023 que valida peticiones, arma prompts, tokeniza, aplica filtros de seguridad y hace streaming de la respuesta. El tráfico creció unas 1,800 veces entre inicios de 2024 y el otoño de 2026, y el overhead de Python en cada paso se volvió caro. Un primer intento parcial, un parser en Rust invocado desde Python, apenas recortó 8-10% de CPU porque cada token cruzaba la frontera entre lenguajes varias veces, así que optaron por una reescritura total.

Claude escribió la primera versión del camino principal de peticiones en cerca de una semana, pero el cuello de botella real fue verificar que el nuevo sistema se comportara igual que producción. Para eso corrieron la versión en Rust en modo shadow sobre tráfico real: el modelo se invoca una sola vez y su salida se reproduce en ambas implementaciones, y en cada etapa del pipeline se comparan huellas (paso, fragmento de prompt, primer byte distinto, longitudes) sin que nadie lea el contenido de las peticiones. Un agente coordinador agrupaba las diferencias nuevas y asignaba a agentes trabajadores que, en sandboxes, reproducían el caso, corregían el código Rust, añadían un test y abrían un PR para revisión humana.

La tasa de coincidencia en entradas pasó de alrededor de 24% en abril a 99.6% en agosto, y el tráfico público se movió a Rust en septiembre sin congelar el desarrollo de features. Las correcciones de los revisores se convirtieron en reglas compartidas (incluida una actualización de CLAUDE.md a partir de unos 60 comentarios de review), lints y un check de merge que exige cambios equivalentes en Rust cuando se toca Python. Para equipos que planean migraciones asistidas por agentes, la lección explícita es que la generación de código ya no es el límite: lo es la infraestructura de verificación.
