GitHub cobrará por defecto a la organización las code reviews de Copilot a partir del 30 de diciembre

Si no hay una preferencia guardada, las revisiones hechas por miembros con licencia de pago se facturarán a la organización dueña del repositorio.

GitHub anunció en su changelog un cambio en cómo se factura Copilot code review. A partir del 30 de diciembre de 2026, cuando un miembro con licencia de pago de Copilot solicite una revisión y no exista una elección de facturación guardada, el costo se cargará a la organización propietaria del repositorio.

Quien quiera conservar el comportamiento actual, en el que el consumo se atribuye al miembro, debe seleccionar esa opción antes de la fecha. Para administradores de organizaciones con muchos colaboradores externos o con licencias repartidas entre varias cuentas, conviene revisar la configuración y los presupuestos antes de fin de año para evitar sorpresas en la factura.
