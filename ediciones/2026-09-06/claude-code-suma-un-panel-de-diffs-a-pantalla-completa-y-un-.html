Agentic coding

Claude Code suma un panel de diffs a pantalla completa y un comando para diagnosticar skills

En dos releases consecutivos, Anthropic añadió un panel `/diff` para revisar cambios sin confirmar y el comando `/skill-doctor`, que expone cuánto contexto consume cada skill cargada en una sesión.

Anthropic publicó dos actualizaciones seguidas de Claude Code esta semana. La versión 2.1.260 introdujo un panel de diffs a pantalla completa -activable con `/diff`- que se abre junto a la conversación y muestra en vivo los cambios sin confirmar mientras Claude edita archivos, útil para revisar ediciones grandes sin salir a una terminal aparte.

Un día después, la 2.1.261 llegó con `/skill-doctor`, un comando pensado para equipos que acumulan muchas skills personalizadas: reporta cuánto contexto consume cada una de las cargadas en la sesión, ayudando a detectar cuándo una skill mal escrita infla el prompt de forma innecesaria. La misma versión mejoró los mensajes de `/status` y `claude doctor` para explicar con más detalle cuando una sesión falla por una política de organización, en vez de mostrar un error genérico.

Ambos cambios son incrementales, pero apuntan a un mismo problema: a medida que los equipos acumulan más contexto persistente -skills, sandboxes, políticas de organización-, Claude Code necesita mejores herramientas de introspección para que developers y administradores entiendan qué pasa dentro de una sesión antes de que se vuelva difícil de depurar.
