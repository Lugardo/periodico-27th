Codex CLI suma emparejamiento remoto, modelos de Bedrock y soporte para skills de Cursor

La CLI de OpenAI ahora genera códigos de emparejamiento para control remoto, importa skills creadas en Cursor y habilita modelos de Amazon Bedrock como GPT-5.6 Sol, Terra y Luna con razonamiento máximo.

OpenAI siguió empujando actualizaciones a Codex CLI esta semana. La más notable en flujo de trabajo es `codex remote-control pair`, un subcomando que genera códigos de emparejamiento manual desde un daemon en ejecución, pensado para conectar un Codex corriendo en una máquina remota -un servidor de CI, una VM en la nube- sin exponer credenciales completas en cada sesión.

En el terreno de modelos, la CLI ahora soporta GPT-5.6 Sol, Terra y Luna servidos vía Amazon Bedrock, con soporte de primera clase para el nivel de esfuerzo de razonamiento máximo, útil para quien ya centraliza su facturación y cumplimiento en AWS y no quiere depender solo de la API directa de OpenAI.

Otro cambio relevante para quien corre varios agentes en paralelo: Codex CLI ahora puede importar skills gestionadas en Cursor y sincronizar cambios en conversaciones importadas de Claude y Cursor sin crear duplicados. Además suma soporte opcional para la especificación 2026-07-28 del Model Context Protocol, que incluye descubrimiento paginado de herramientas, solicitudes de múltiples rondas y arranque de servidores MCP sin bloqueo, cambios que deberían reducir la latencia al conectar Codex con servidores MCP grandes.
