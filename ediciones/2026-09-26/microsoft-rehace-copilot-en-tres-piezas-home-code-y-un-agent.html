Microsoft rehace Copilot en tres piezas: Home, Code y un agente que trabaja solo

Microsoft reorganizó su familia Copilot en tres productos —Home, Code y Autopilot— mientras GitHub Copilot suma nuevos modelos y controles de seguridad para agentes.

Microsoft anunció el 25 de septiembre una reorganización de su familia Copilot en tres productos diferenciados: Copilot Home, pensado como asistente conversacional para el día a día; Copilot Code, enfocado en programación; y Autopilot, un agente capaz de ejecutar tareas de forma autónoma sin supervisión constante. La compañía busca ordenar una oferta que se había vuelto confusa tanto para desarrolladores como para usuarios finales, y competir de frente con Anthropic y OpenAI en el terreno corporativo.

En paralelo, GitHub publicó su resumen semanal de novedades para GitHub Copilot. Entre los cambios: la llegada de Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna y Grok 4.7 como modelos disponibles según el plan contratado; un sandboxing local en vista previa pública que limita el acceso de los agentes a archivos, red y credenciales; soporte para monitoreo de la actividad de los agentes vía OpenTelemetry configurable desde ajustes empresariales; y "aprobaciones asistidas", que autorizan de forma automática las acciones de bajo riesgo mientras piden confirmación explícita para las más sensibles.

Para quien desarrolla software el mensaje es doble: por un lado, más variedad de modelos y mejor integración con Slack, Microsoft Teams, JetBrains y VS Code; por otro, un endurecimiento visible de los controles alrededor de los agentes autónomos, señal de que las empresas de herramientas de codificación están respondiendo a la preocupación creciente por agentes que actúan con poca supervisión.
