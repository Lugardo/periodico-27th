Anthropic abre el portal para publicar plugins y conectores MCP de Claude

Anthropic lanzó un portal de envío para que desarrolladores con planes pagos publiquen plugins y conectores MCP en el directorio oficial de Claude, con validación y escaneo de seguridad automáticos.

Anthropic anunció el 25 de septiembre la apertura de un portal de envío de plugins para Claude, que permite a desarrolladores en planes pagos someter dos tipos de paquete: un conector MCP individual que apunta a un servidor remoto, o un paquete completo que combina servidores MCP con skills, alojado como repositorio en GitHub. Cada envío pasa por validación automática y un escaneo de seguridad apenas se sube, y los desarrolladores pueden seguir el estado de la revisión y consultar analítica de uso una vez que el plugin queda publicado.

La compañía describe los plugins como el formato principal para distribuir extensiones en claude.ai, las apps de escritorio y móvil, Cowork y Claude Code, y asegura que el uso de MCP dentro de sus productos creció 110 veces en lo que va del año. El movimiento llega pocos días después del lanzamiento de Claude Opus 5.5 y busca ordenar un ecosistema de terceros que hasta ahora dependía de servidores MCP dispersos por GitHub, acercándolo más al modelo de revisión de una tienda de aplicaciones.
