Claude Code suma evaluaciones de plugins y nuevos estilos de salida

Anthropic añadió un comando para medir objetivamente si un plugin o skill realmente mejora las respuestas de Claude, junto con nuevos estilos de salida educativos.

Anthropic publicó una actualización amplia de Claude Code que introduce `claude plugin eval`, un comando pensado para que quienes desarrollan plugins y skills puedan medir su impacto real. La herramienta corre el plugin contra un conjunto de prompts representativos, califica lo que produce Claude con seis tipos de evaluador —cuatro gratuitos y dos que facturan un modelo juez, para evaluación por LLM y comparación contra línea base— y compara el resultado contra una ejecución sin el plugin cargado.

Esto responde a tres preguntas que antes eran difíciles de contestar con datos: si el skill realmente se activa cuando debería, si sigue funcionando tras una edición o un cambio de modelo, y si de verdad mejora sobre lo que el modelo haría sin ayuda. Para equipos que mantienen varios plugins internos, es un paso hacia tratar esas herramientas como código con pruebas, y no como prompts sueltos.

La misma actualización trae el cambio dinámico de estilos de salida, incluyendo dos nuevos estilos educativos integrados, "Explanatory" y "Learning", pensados para quienes usan Claude Code como apoyo de aprendizaje. También se incluyen mejoras de estabilidad en el caché de prompts, control de telemetría y ajustes de rendimiento en CLI, VS Code, la versión web y la integración con Slack.
