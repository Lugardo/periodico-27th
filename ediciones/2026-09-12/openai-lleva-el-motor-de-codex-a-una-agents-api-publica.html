Agentic coding

OpenAI lleva el motor de Codex a una Agents API pública

La compañía abrió en beta pública una API que expone la misma infraestructura de orquestación que usa Codex, para construir agentes que corren horas, ejecutan código y coordinan subagentes.

OpenAI publicó el 10 de septiembre la Agents API en beta pública, dejando disponible para cualquier desarrollador el mismo "harness" (motor de orquestación) que impulsa a su agente de programación Codex. En la práctica, quien desarrolla define una tarea, un modelo, un conjunto de herramientas y un entorno de cómputo, y OpenAI se encarga de gestionar sesiones, coordinación de herramientas y recuperación ante fallos.

Entre las capacidades destacadas están la gestión automática de contexto, el uso paralelo de herramientas y la posibilidad de delegar subtareas a subagentes, funciones que antes requerían construir infraestructura propia. Para el entorno de ejecución, OpenAI ofrece sandboxes propios además de integraciones con socios como Cloudflare, Modal, E2B, DigitalOcean, Oracle y Vercel, o la opción de correr los agentes sobre infraestructura del propio desarrollador.

No hay cargo adicional por usar la API: se paga solo por los tokens y herramientas que consuman los agentes. Early adopters citados por OpenAI, como Hypha y Ciridae, reportan mejoras notables en latencia y tasa de fallos tras migrar a este motor gestionado, lo que sugiere que la propuesta apunta directamente a equipos que hoy mantienen su propia capa de orquestación de agentes.
