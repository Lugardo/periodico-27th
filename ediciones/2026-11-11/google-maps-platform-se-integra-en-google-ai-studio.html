Google Maps Platform se integra en Google AI Studio

Ahora se pueden generar apps con mapas, Places, Routes y datos ambientales desde un prompt en AI Studio, con configuración de API keys automática y cuota gratuita para prototipos.

Google integró Maps Platform dentro de Google AI Studio. Basta describir la app a Gemini para que AI Studio configure los servicios de Maps, gestione las API keys y cargue un mapa interactivo en el panel de vista previa. Las APIs disponibles incluyen Maps, Places, Routes y Environment, lo que abre la puerta a localizadores de tiendas, planificadores de rutas, recorridos 3D o monitores de calidad del aire.

Para prototipar no se necesita tarjeta de crédito: las credenciales de demo incluyen una cuota diaria gratuita por API pensada para pruebas y apps web dentro de AI Studio. Para llevar algo a producción en web o móvil hay que pasar a un proyecto con facturación.

Google publicó además varias arquitecturas de referencia remixables en la galería de AI Studio como punto de partida.
