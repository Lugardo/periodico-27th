Claude Code 2.1.238 suma atajos de teclado configurables y corrige una fuga de memoria en sesiones largas

La versión del 20 de agosto agrega un modo de atajos tipo readline, ayudas para marketplaces de plugins y soporte para proxies corporativos que renuevan su autenticación en cada solicitud.

Anthropic publicó la versión 2.1.238 de Claude Code el 20 de agosto, un día después de la 2.1.237. La novedad más visible es la nueva configuración keybindingFlavor, que permite adoptar atajos de teclado al estilo readline -como Ctrl+W para borrar la palabra anterior- para quienes vienen de terminales Unix tradicionales. La versión también agrega funciones auxiliares de cabeceras para quienes publican o consumen marketplaces de plugins, y una bandera --defer-shutdown-max-min pensada para runners autoalojados que necesitan terminar el trabajo en curso antes de apagarse.

En el frente de infraestructura corporativa, esta versión suma soporte para proxies que exigen renovar la cabecera Proxy-Authorization en cada solicitud, un escenario común en redes empresariales con autenticación por token de corta duración. También corrige un problema de crecimiento de memoria que aparecía en sesiones interactivas largas, además de arreglos menores en estilos de salida personalizados, permisos de workspace y conexiones MCP.

Son cambios de mantenimiento más que una novedad mayor, pero confirman el ritmo casi diario de publicación que Claude Code viene sosteniendo desde mediados de agosto.
