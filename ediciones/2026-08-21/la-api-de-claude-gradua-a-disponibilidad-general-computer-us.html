La API de Claude gradúa a disponibilidad general computer use, browser use, Files API y Agent Skills

Anthropic sacó del beta cinco piezas clave de su plataforma para desarrolladores el mismo día: controlar un escritorio completo o solo un navegador, subir archivos, cargar Skills y gestionar usuarios de Enterprise, todo sin cabeceras beta.

Anthropic publicó el 19 de agosto un paquete de novedades para la Claude API que saca de beta varias piezas que muchos equipos ya usaban en producción. La herramienta de computer use pasa a disponibilidad general como el toolset computer_toolset_20260801: ya no necesita cabecera beta, permite agrupar varias acciones en un mismo turno, activa zoom por defecto y admite configuración por miembro. Junto a ella debuta browser use, un toolset pensado para manejar un navegador que aloja la propia aplicación en vez de un escritorio completo: lee el árbol de accesibilidad de la página, sus elementos y pestañas, y agrega referencias a elementos, entrada de formularios y gestión de descargas. Ambas herramientas funcionan con Claude Fable 5, Mythos 5, Opus 5, Sonnet 5 y Opus 4.8.

El mismo lote confirma la disponibilidad general de la Files API y de Agent Skills -incluida la API de Skills-, ambas sin requerir ya sus cabeceras beta, aunque las solicitudes que todavía las envíen siguen funcionando durante la transición. También llegó a GA el manejo de usuarios de Claude Enterprise a través de la Admin API (miembros, invitaciones, grupos y roles personalizados), y se sumó la posibilidad de restringir a qué dominios pueden acceder las herramientas web_search y web_fetch en Claude Managed Agents.

Para cerrar el paquete, las sesiones de Managed Agents que corren en un sandbox autoalojado ahora pueden montar almacenes de memoria persistente, y el visor de sesiones de la Consola de Claude se rediseñó con un minimapa de línea de tiempo, una transcripción agrupada por solicitud de modelo y un panel de inspección con costos y estadísticas por herramienta. En conjunto, es uno de los lotes de novedades más grandes que Anthropic ha publicado de una sola vez para su plataforma de desarrolladores en lo que va de agosto.
