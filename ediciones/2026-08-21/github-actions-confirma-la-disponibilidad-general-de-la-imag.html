GitHub Actions confirma la disponibilidad general de la imagen Windows 11 arm64 con Visual Studio 2026

Los runners hospedados por GitHub ya pueden compilar en Windows sobre arm64 con la toolchain de Visual Studio 2026 usando la etiqueta windows-11-vs2026-arm, con la migración por defecto prevista para fines de septiembre.

GitHub confirmó el 20 de agosto que la imagen de Windows 11 arm64 con Visual Studio 2026 pasó de preview público a disponibilidad general en los runners estándar y en los runners más grandes hospedados por GitHub. Para usarla en un workflow de GitHub Actions basta con apuntar runs-on a windows-11-vs2026-arm.

La compañía adelantó además un calendario de migración: a partir del 21 de septiembre empezará a actualizar gradualmente la imagen windows-11-arm por defecto para que use Visual Studio 2026, con el proceso completo previsto para el 30 de septiembre. Es un cambio que puede romper workflows que dependen explícitamente de herramientas o rutas de Visual Studio 2022, por lo que GitHub recomienda a los equipos que compilan para Windows en arm64 revisar sus pipelines antes de esa fecha.

La imagen se suma a un esfuerzo más amplio de GitHub por absorber directamente el mantenimiento de las imágenes arm64 para runners hospedados, trabajo que antes corría por cuenta de Arm Limited.
