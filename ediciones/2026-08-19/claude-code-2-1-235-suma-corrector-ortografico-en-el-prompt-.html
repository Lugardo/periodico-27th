Claude Code 2.1.235 suma corrector ortográfico en el prompt y corrige bugs de caché y UI

La nueva versión de Claude Code agrega un corrector ortográfico opcional mientras se escribe, además de arreglos en la caché de prompts y en el renderizado de listas en la terminal.

Anthropic publicó la versión 2.1.235 de Claude Code el 18 de agosto. La novedad principal es un corrector ortográfico opcional que subraya palabras mal escritas en el campo de prompt mientras se escribe, apoyado en los correctores locales aspell, hunspell o ispell ya instalados en el sistema.

La actualización también corrige un bug donde la caché completa del prompt se invalidaba cada vez que un language server se desconectaba y reconectaba a mitad de sesión, lo que generaba costos y latencia innecesarios. Además ajusta el renderizado de listas Markdown anidadas a partir del tercer nivel de profundidad, agrega sangría colgante a los ítems de lista que se envuelven en la terminal, y soluciona un desfase de varios caracteres en el resaltado de texto dentro de prompts multilínea.

Son cambios menores en apariencia, pero típicos del ritmo casi diario de iteración que Anthropic mantiene sobre su herramienta de coding agéntico, apuntando sobre todo a pulir la experiencia diaria en terminal de quienes ya la usan a diario.
