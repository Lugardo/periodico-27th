Agents API en beta pública y nueva Decisions API para clasificar y enrutar

OpenAI abre una API de agentes con ejecución hospedada, memoria y computer use, y una API de decisiones basada en Luna para respuestas de conjunto cerrado.

La Agents API entra en beta pública con ejecución hospedada, memoria, herramientas y soporte multiagente. Además incorpora computer use, de modo que los agentes pueden operar software a través de su interfaz, y trae a las aplicaciones capacidades de Codex como tool search, tool calling y compactación de contexto.

La Decisions API usa una versión de GPT-6 Luna para responder preguntas definidas por el desarrollador con un conjunto finito de respuestas posibles, recibiendo texto o imágenes como contexto. Sirve para clasificar contenido, enrutar peticiones o elegir el siguiente paso de un agente, y según los reportes es unas diez veces más rápida que Luna en la API normal.
