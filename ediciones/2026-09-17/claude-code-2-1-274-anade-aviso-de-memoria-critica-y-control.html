Claude Code 2.1.274 añade aviso de memoria crítica y controles finos para MCP

La nueva versión avisa cuando el uso de memoria se vuelve crítico, deja configurar el tiempo de espera al arrancar servidores MCP y repara sesiones que quedaban atascadas por errores de tool_use_id.

Anthropic publicó la versión 2.1.274 de Claude Code, centrada en estabilidad operativa más que en features nuevas. La CLI ahora muestra una advertencia visible cuando el uso de memoria del proceso llega a niveles críticos, con sugerencias concretas para liberar memoria o reiniciar la sesión antes de que falle.

Para quien administra servidores MCP, la nueva variable de entorno CLAUDE_CODE_MCP_STARTUP_WAIT_MS permite controlar cuánto tiempo espera Claude Code a que un servidor MCP arranque antes de continuar, incluyendo la opción de no esperar en absoluto (valor 0). La versión también agrega el atributo effort a los traces de OpenTelemetry, útil para quien instrumenta el uso de la herramienta en flujos propios.

Entre las correcciones, destaca que las sesiones que quedaban atascadas por errores de "unexpected tool_use_id" ahora se auto-reparan en lugar de requerir reiniciar manualmente, se corrigió la pérdida del /goal activo al reanudar sesiones que habían sido compactadas, y mejoró el manejo de errores de autenticación MCP del tipo 403 insufficient_scope, un problema recurrente en integraciones con gateways de terceros.
