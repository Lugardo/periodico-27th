Agentic coding

Visual Studio Code 1.138 lleva los agentes a Dev Containers y amplía el soporte de Codex

La actualización permite correr agentes dentro de Dev Containers con las herramientas del proyecto, extiende las sesiones de Codex entre aplicaciones y añade limpieza automática de sesiones terminadas.

Microsoft publicó la versión 1.138 de Visual Studio Code, que amplía cómo los agentes de código interactúan con el entorno de desarrollo. La novedad principal es la posibilidad de correr agentes dentro de un Dev Container local, con acceso a las mismas herramientas y dependencias configuradas para el proyecto, en lugar de operar en el entorno general de la máquina.

El editor también expande el harness de Codex: ahora las sesiones se pueden continuar entre distintas aplicaciones, es posible elegir entre una suscripción de Copilot o de ChatGPT para correrlas, y el agente gana acceso a las herramientas nativas de VS Code durante esas sesiones. Se suma además una función de limpieza de sesiones en preview, que marca automáticamente como terminadas las sesiones cuyos cambios ya se fusionaron y permite borrarlas después de un periodo de gracia configurable.

El paquete se completa con el despliegue gradual del modo de voz para Copilot, disponible únicamente en planes individuales de GitHub Copilot y todavía no habilitado para todas las cuentas elegibles.
