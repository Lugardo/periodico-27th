Codex CLI de OpenAI mejora la edición en terminal, suma búsqueda web indexada y avisos de uso anticipados

La versión 0.154.0 del cliente de línea de comandos de Codex trae deshacer/rehacer en modo vim, historial completo de sesión, una forma más controlada de buscar en la web y recordatorios de tiempo programados.

OpenAI publicó una actualización amplia de Codex CLI, la interfaz de terminal para su agente de programación. El modo vim ahora soporta deshacer con 'u' y rehacer con Ctrl+R conservando los borradores completos, incluido contenido pegado y adjuntos, mientras que el historial de la interfaz de texto muestra parches completos, comandos enviados a procesos en segundo plano y comandos ya ejecutados, algo pensado para sesiones largas donde perder ese rastro es costoso.

La actualización también agrega un modo de búsqueda web indexada que permite consultas en vivo pero restringe el acceso directo a páginas solo a URLs aprobadas por el servidor, una forma de acotar el riesgo de que el agente navegue a contenido no verificado durante una tarea. A la vez, Codex puede ahora recibir recordatorios de tiempo programados en UTC y consultar la hora actual directamente, incluso a través del reloj que exponga la aplicación cliente.

Entre los arreglos más puntuales, se corrigió un problema de renderizado en la interfaz de terminal en Linux al suspender el proceso con Ctrl+Z y reanudarlo con 'fg', además de ajustes en la gestión del marketplace de plugins y nuevas opciones de configuración. La versión se instala con pip install --upgrade openai-codex==0.154.0.
