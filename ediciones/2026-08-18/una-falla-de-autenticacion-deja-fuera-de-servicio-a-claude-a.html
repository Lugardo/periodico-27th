Una falla de autenticación deja fuera de servicio a Claude.ai, Claude Code y la API durante 36 minutos

La interrupción del 16 de agosto impidió iniciar sesión en Claude.ai, Claude Code, la API y Cowork; Anthropic confirmó la restauración completa del servicio unos 40 minutos después de detectar el problema.

Anthropic sufrió una interrupción que afectó simultáneamente a Claude.ai, Claude Code, la API y Claude Cowork la noche del 16 de agosto. Según la página de estado de la compañía, el problema comenzó cerca de las 21:58 UTC como una falla que impedía a algunos usuarios autenticarse; nueve minutos después Anthropic ya reportaba degradación general en Claude.ai y platform.claude.com. El servicio quedó restablecido por completo hacia las 22:40 UTC, unos 36 minutos después del primer reporte.

Durante la ventana de la falla, los usuarios afectados no podían iniciar sesión, las solicitudes no se completaban o la interfaz simplemente no cargaba, tanto en el chat como en las integraciones de Claude Code usadas en flujos de trabajo de desarrollo. Para equipos que dependen de Claude Code en pipelines de CI o en sesiones programadas, este tipo de cortes, aunque breves, son un recordatorio de que conviene tener manejo de reintentos y alertas propias sobre la disponibilidad del servicio, en vez de asumir continuidad total.
