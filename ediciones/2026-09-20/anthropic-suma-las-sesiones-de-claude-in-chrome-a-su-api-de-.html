Anthropic suma las sesiones de Claude in Chrome a su API de cumplimiento para empresas

En beta para organizaciones Enterprise, la Compliance API ahora también devuelve transcripciones completas de las sesiones que corren dentro de Claude in Chrome.

Anthropic amplió el 18 de septiembre su Compliance API para que los endpoints de sesiones locales devuelvan también las transcripciones generadas por Claude in Chrome, identificadas con el valor product_surface igual a claude_in_chrome. La función está en beta para organizaciones Claude Enterprise y funciona con la misma Compliance Access Key y el scope read:compliance_user_data que ya usan otros tipos de sesión.

Es una pieza de gobernanza más que de producto de cara al usuario final, pero relevante para cualquier equipo de TI o seguridad que esté evaluando desplegar agentes de navegador a escala: da visibilidad centralizada sobre lo que un agente hizo dentro del navegador de un empleado, en el mismo formato que ya se usaba para auditar otras superficies de Claude.

El movimiento encaja con un patrón más amplio de esta semana en la industria: a medida que los agentes ganan acceso directo a navegadores —tanto en Claude in Chrome como en el navegador integrado de ChatGPT—, los proveedores están reforzando en paralelo las herramientas de auditoría y cumplimiento que permiten a las empresas rastrear esa actividad.
