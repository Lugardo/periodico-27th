Agentic coding

Google lleva su agente de código Antigravity a la API de Gemini con nuevas herramientas para manejar archivos y credenciales

Google estrenó el harness "antigravity-preview-09-2026" en la Interactions API y en AI Studio, junto con una Files API y una Credentials API pensadas para que los agentes usen servicios externos sin exponer tokens al modelo.

Google anunció en su blog oficial de desarrolladores la llegada de un nuevo harness de agentes a la API de Gemini, llamado antigravity-preview-09-2026, que traslada a la propia API buena parte del comportamiento y las herramientas de su agente de codificación Antigravity. Con una sola llamada, según la compañía, un desarrollador puede levantar un agente de Gemini capaz de razonar, ejecutar código, administrar archivos y navegar la web dentro de un sandbox de Linux aislado que corre sobre Gemini 3.8 Flash, con el modelo configurable por cada interacción. La función ya está disponible tanto en la Interactions API como en Google AI Studio.

Junto con el nuevo harness, Google introdujo dos piezas complementarias: una Files API para mover datos dentro y fuera del entorno aislado del agente (subir insumos, listar lo que el agente generó y descargar solo el archivo necesario), y una Credentials API que permite registrar una credencial una sola vez y asociarla a un servidor MCP o a una variable de entorno del sandbox, de forma que el modelo nunca llega a ver el secreto directamente.

La actualización apunta a un problema muy concreto para quienes construyen agentes en producción: dar acceso a servicios externos como GitHub o Slack sin tener que pasarle las claves al propio modelo. Al resolverlo a nivel de API, Google busca competir de frente con las plataformas de agentes de OpenAI y Anthropic, que enfrentan el mismo reto de aislar credenciales sensibles en flujos donde un modelo ejecuta código de forma autónoma.
