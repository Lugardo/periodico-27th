Claude Code endurece su sandbox, la industria se une en torno a SGLang y Cloudflare libera su navegador para agentes

Domingo tranquilo en anuncios: ninguno de los grandes laboratorios publicó nada nuevo en las últimas 24 horas. Por eso esta edición recoge lo que quedó pendiente de la semana y que importa a quien desarrolla software: cambios de seguridad en los agentes de código, una alianza para la inferencia abierta, un navegador open source para agentes y una demanda que busca congelar la IA de frontera.

Agentic coding

Claude Code 2.1.325 vuelve a pedir permiso para los comandos que corren en sandbox

La nueva versión cambia un comportamiento por defecto: los comandos Bash dentro del sandbox ya no se aprueban solos. También corrige un fallo de seguridad en la descompresión zstd y añade sugerencias de prompt en VS Code.

LMSYS forma el SGLang Consortium con NVIDIA, AMD, Intel, Google y Meta

Ocho empresas se suman como miembros fundadores para coordinar el roadmap del motor de inferencia SGLang. El proyecto sigue con licencia Apache 2.0 y los maintainers conservan el control técnico.

Cloudflare libera Kitesurf, su motor de navegador para agentes, bajo Apache 2.0

El navegador experimental que Cloudflare diseñó para agentes ya es open source. Se puede inspeccionar, correr en local o desplegar en Workers.

Codex CLI 0.168.0 suma túneles con ProxyCommand y elección de modelo en la nube

La nueva versión del CLI de Codex permite usar `codex tcp-tunnel` como ProxyCommand de OpenSSH. También deja elegir modelo y nivel de razonamiento en las conversaciones Cloud.

Anthropic lanza Claude for Manufacturing, un plugin con 17 skills para la planta

El plugin conecta a Claude con Autodesk Fusion, Infor, Microsoft 365 y Oracle NetSuite para cotizar, documentar inspecciones y diagnosticar fallas. No opera maquinaria.

Cuatro ONG demandan a OpenAI, Anthropic, Google, Meta y SpaceX para congelar la IA de frontera

La demanda, presentada en San Francisco, pide prohibir que se entrenen o desplieguen modelos más capaces que los actuales. Todavía no hay resolución.
