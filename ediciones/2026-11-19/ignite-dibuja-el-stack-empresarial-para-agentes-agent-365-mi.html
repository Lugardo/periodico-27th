Ignite dibuja el stack empresarial para agentes: Agent 365, Microsoft IQ y Entra Agent Identity

Microsoft amplía Agent 365 para monitorear riesgos y permisos de agentes, unifica contexto de negocio en Microsoft IQ y lleva la identidad de agentes de Entra a disponibilidad general.

La segunda jornada de Ignite completó el cuadro de cómo Microsoft quiere que las empresas construyan y operen agentes. Agent 365 suma herramientas para monitorear el uso de IA, evaluar riesgos y administrar identidades, permisos y acceso de los agentes a aplicaciones externas.

Microsoft IQ agrupa Work IQ, Fabric IQ, Foundry IQ y Web IQ como capa de contexto: da a los agentes acceso a datos de aplicaciones de negocio, documentos internos y fuentes externas desde un mismo punto. En identidad, Entra Agent Identity pasa a disponibilidad general, y la compañía también presentó Perception, un sistema de seguridad que coordina agentes para simular ataques, detectar amenazas y automatizar remediación.

Para quien construye agentes sobre Azure, el mensaje es que identidad, permisos y observabilidad dejan de ser piezas opcionales: la plataforma espera que cada agente tenga identidad propia y quede bajo gobierno central.
