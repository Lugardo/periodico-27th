Copilot SDK 2.0 llega con sesiones múltiples y persistentes en seis lenguajes

El antiguo GitHub Copilot SDK, ahora Microsoft Copilot SDK, alcanza la versión 2.0 en Ignite: un mismo proceso puede alojar varias sesiones aisladas que sobreviven a su cliente.

En Ignite 2026, Microsoft presentó Copilot SDK 2.0, el kit que expone el mismo runtime agéntico que usa la app de Copilot. El cambio principal es de arquitectura: un solo proceso puede alojar varias sesiones, cada una con su propio estado, credenciales, herramientas, archivos e historial, y las sesiones persisten aunque se cierre el proceso o el cliente que las creó.

El SDK está disponible para TypeScript, Python, Go, .NET, Java y Rust. GitHub ya había anunciado en octubre que el producto pasaba a llamarse Microsoft Copilot SDK sin requerir cambios inmediatos a quienes ya lo usan.

En el mismo paquete de anuncios, Microsoft dijo que los agentes y flujos de Copilot Studio podrán construirse en local y publicarse desde la línea de comandos con control de versiones en GitHub, y que GitHub Copilot ahora acompaña repos de Azure DevOps desde el clone hasta el merge, con code review local, detección de secretos y contexto entre repositorios.
