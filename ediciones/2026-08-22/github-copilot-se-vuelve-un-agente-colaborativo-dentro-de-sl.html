Agentic coding

GitHub Copilot se vuelve un agente colaborativo dentro de Slack y Microsoft Teams

GitHub lleva su agente en la nube a Slack y Microsoft Teams: se le puede mencionar en un canal para que investigue, planifique y ejecute cambios de código mientras el equipo sigue el progreso.

GitHub anunció dos integraciones el 21 de agosto que llevan las capacidades agénticas de Copilot a las herramientas donde ya coordinan trabajo los equipos. En Microsoft Teams, mencionar a @GitHub en un canal, hilo o mensaje directo arranca una sesión de Copilot cloud agent; cualquier persona en la conversación puede sumar contexto, hacer preguntas o ayudar a planear el trabajo, y Copilot crea un canal de código dedicado donde todos pueden seguir el avance.

En paralelo, la integración de GitHub en Slack entra en vista previa pública con las capacidades agénticas de GitHub Copilot CLI y de la app de Copilot: desde una conversación de Slack se puede pedir a @GitHub que planifique cambios, investigue un problema o se haga cargo de una tarea de código, sin salir del canal donde el equipo ya está discutiendo el tema.

El movimiento apunta a bajar la fricción de coordinar trabajo agéntico en equipos que viven en Slack o Teams más que en la propia interfaz de GitHub, acercando la revisión y el seguimiento de tareas de Copilot al lugar donde ya ocurre la conversación del equipo.
