X lanza un servidor MCP para que cualquier IA gestione campañas de anuncios

X Ads MCP conecta agentes compatibles con Model Context Protocol —incluido Grok, pero también agentes de terceros— a las herramientas de su plataforma publicitaria mediante lenguaje natural.

X lanzó X Ads MCP, un servidor remoto de Model Context Protocol integrado en su API de anuncios (ads-api.x.com/mcp) que expone 23 herramientas para leer datos de campañas, correr analítica y gestionar anuncios en curso. Cualquier agente compatible con MCP —no solo Grok— puede conectarse usando el propio token OAuth2 del anunciante, de forma que el agente únicamente ve las cuentas publicitarias a las que ese usuario ya tiene acceso.

En la práctica, un anunciante puede pedirle a su agente de IA en lenguaje natural que lance una campaña, revise su rendimiento, pause anuncios de bajo desempeño o ajuste presupuestos y creatividades, sin salir de la interfaz de chat que ya usa.

El lanzamiento es otra señal de que Model Context Protocol —el estándar impulsado originalmente por Anthropic— se está consolidando como la vía por defecto para que plataformas expongan sus capacidades a agentes de terceros, sumándose a servidores MCP similares que ya ofrecen Meta y Google para sus propias plataformas de anuncios.
