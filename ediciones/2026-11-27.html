Anthropic detalla cómo agentes de Claude migraron la Messages API de Python a Rust sin apagar el servicio

El equipo reescribió por completo el servicio que atiende cada petición a Claude; el resultado usa cerca de 70% menos CPU y más de 80% menos memoria por petición, con un time to first token ~20% menor.
