Claude Code suma soporte para AGENTS.md y mueve el clasificador de Auto mode al servidor

Las versiones 2.1.275 a 2.1.278 de Claude Code, lanzadas esta semana, agregan lectura de AGENTS.md como alternativa a CLAUDE.md, controles más finos de sandboxing y gateways, y un Auto mode que ahora clasifica en el servidor sin costo extra de latencia.

Anthropic encadenó varias versiones de Claude Code entre el 17 y el 19 de septiembre. La más notable para quien mantiene monorepos o plantillas compartidas es el soporte de AGENTS.md: si un proyecto no tiene un archivo CLAUDE.md, Claude Code ahora puede leer AGENTS.md en su lugar, con la opción configurable desde "Project instructions" en /config (por ahora no disponible en Bedrock, Vertex ni Foundry).

Otro cambio de fondo es que Auto mode pasa a usar por defecto un clasificador que corre del lado del servidor, sin el costo de overhead que tenía antes, aplicable a Claude API, Enterprise, Bedrock, Vertex, Foundry y gateways (con opción de desactivarlo vía variable de entorno). En sandboxing se agregó control granular por comando de allowed_domains para Bash, PowerShell y Monitor en Auto mode, además de una corrección a un patrón de exclusión que antes eximía comandos compuestos completos en lugar de evaluar cada parte por separado.

El ciclo de releases también trajo mejoras a la extensión de VS Code —mapa de agentes con shells en segundo plano y tareas visibles, botón para copiar respuestas, cierre de sesión desde el panel— y corrigió errores que hacían fallar sesiones con el mensaje "text content blocks must be non-empty", además de un bug crítico de un release anterior que rompía cualquier request cuando ANTHROPIC_BASE_URL apuntaba a un proxy o gateway.
