Anthropic lanza Claude for Manufacturing, un plugin con 17 skills para la planta

El plugin conecta a Claude con Autodesk Fusion, Infor, Microsoft 365 y Oracle NetSuite para cotizar, documentar inspecciones y diagnosticar fallas. No opera maquinaria.

Anthropic presentó Claude for Manufacturing, un plugin con 17 skills ya configuradas para equipos de producción: estimadores, ingenieros de calidad, técnicos y compradores. Está disponible para los planes Team y Enterprise.

Las skills sirven para preparar cotizaciones, documentar inspecciones fallidas, diagnosticar fallas de máquinas, buscar proveedores de equipo y armar reportes de producción con salida, tiempos muertos y costos. Se integran con Autodesk Fusion, Infor, Microsoft 365 y Oracle NetSuite. Si una planta usa software sin conector, puede exportar sus datos a Microsoft 365 para que Claude los lea.

Anthropic aclara que Claude no opera equipos y que los ingenieros siguen aprobando cotizaciones, inspecciones y reparaciones. Infor tiene un plugin aparte que sí permite hacer cambios aprobados, como liberar órdenes de compra o reprogramar la producción. La compañía anunció más skills y un webinar técnico para el 17 de noviembre.

Para quien construye plugins, es un buen ejemplo de cómo Anthropic empaqueta skills y conectores por industria.
