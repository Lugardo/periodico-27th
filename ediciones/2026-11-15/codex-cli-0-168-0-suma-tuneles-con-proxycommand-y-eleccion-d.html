Codex CLI 0.168.0 suma túneles con ProxyCommand y elección de modelo en la nube

La nueva versión del CLI de Codex permite usar `codex tcp-tunnel` como ProxyCommand de OpenSSH. También deja elegir modelo y nivel de razonamiento en las conversaciones Cloud.

OpenAI registró el 13 de noviembre en su changelog oficial la versión 0.168.0 de Codex CLI. La versión añade un modo ProxyCommand de OpenSSH para `codex tcp-tunnel`, de modo que el túnel puede usarse directamente desde la configuración de SSH. También permite elegir el modelo y el nivel de esfuerzo de razonamiento en las conversaciones Cloud.

La 0.168.0 sigue de cerca a la 0.167.2 del 11 de noviembre. Esa versión hizo que, en Google Cloud Vertex AI, Codex envíe por defecto las actualizaciones de herramientas de forma incremental (se puede desactivar). También agregó `codex queue --resume` para retomar hilos descargados después de encolar un mensaje.

Algunos agregadores ya mencionan una 0.169.0, pero el changelog de OpenAI todavía no la muestra con notas propias.
