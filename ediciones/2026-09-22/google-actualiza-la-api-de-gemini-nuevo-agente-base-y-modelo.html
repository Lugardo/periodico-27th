Google actualiza la API de Gemini: nuevo agente base y modelos de voz en tiempo real

Antigravity Agent 09-2026 reemplaza a la versión de mayo con cambios que rompen compatibilidad para quien parsea las llamadas a herramientas, mientras debutan Gemini 3.8 Live y su variante con razonamiento extendido.

El changelog de la API de Gemini registró el 21 de septiembre el lanzamiento de Antigravity Agent 09-2026, que sustituye y deprecia a antigravity-preview-05-2026; este último se apagará el 5 de octubre. Quien solo lee los campos output_text o model_output desde un sandbox remoto puede migrar cambiando el nombre del agente, sin más ajustes.

Quien ejecuta las herramientas de forma local o parsea directamente los pasos de function_call sí enfrenta cambios que rompen compatibilidad: los parámetros de las herramientas integradas ahora usan PascalCase en vez de snake_case, y las ediciones de archivo se expresan como reemplazos por rango de líneas en lugar de reescrituras completas del archivo.

La misma actualización trae dos modelos nuevos de audio a audio pensados para aplicaciones de voz en tiempo real, Gemini 3.8 Live y Gemini 3.8 Live Extended Thinking, mientras que el endpoint existente gemini-omni-flash-preview queda marcado para deprecarse el 30 de septiembre.
