Anthropic rediseña Projects en Claude Code para coordinar hilos de agentes en paralelo

La nueva versión, en beta desde el 17 de septiembre, convierte un proyecto en un coordinador de varios hilos de trabajo con memoria compartida, en vez de una simple carpeta de archivos.

Anthropic comenzó a distribuir el 17 de septiembre una versión rediseñada de Projects para Claude Code que cambia el concepto de fondo: en lugar de una carpeta donde se acumulan archivos y contexto, el proyecto pasa a funcionar como un coordinador que reparte el trabajo entre varios hilos de agentes que corren en paralelo, compartiendo memoria y una biblioteca común de archivos y artefactos.

En la práctica, quien usa la función describe qué necesita que se resuelva y Claude se encarga de organizar ese trabajo entre las sesiones en la nube abiertas dentro del proyecto, en vez de que la persona reparta manualmente las tareas entre distintos chats o ramas.

El acceso a la beta arrancó limitado a un grupo de suscriptores Pro y Max que ya usaban sesiones en la nube de Claude Code y no tenían proyectos previos en la versión web o de escritorio. Anthropic dijo que ampliará el acceso durante la semana siguiente al resto de usuarios de Claude Code en esos planes, y que la función llegará después a los planes Team y Enterprise.
