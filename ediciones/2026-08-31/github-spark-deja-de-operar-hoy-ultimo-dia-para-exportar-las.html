GitHub Spark deja de operar hoy: último día para exportar las apps creadas con la herramienta

La herramienta de GitHub para crear apps completas a partir de lenguaje natural llega a su fecha límite de retiro; quienes la usaron deben exportar su código antes de perder el acceso al editor.

GitHub anunció a inicios de agosto el retiro de Spark, su editor experimental para construir aplicaciones completas describiéndolas en lenguaje natural, y hoy 31 de agosto se cumple el plazo final. Desde el 4 de agosto la herramienta ya no aceptaba usuarios nuevos ni la creación de apps adicionales; a partir de hoy, quienes tengan proyectos hechos en Spark pierden la posibilidad de seguir editándolos ahí si no exportaron el código a un repositorio propio.

Las apps ya publicadas seguirán funcionando después del retiro, pero con una salvedad importante para los proyectos que dependían de la función llm() integrada en Spark: ese servicio de inferencia, provisto por GitHub Models, dejó de responder desde el 30 de julio, así que cualquier app que no haya sido migrada a un proveedor de inferencia propio ya tiene sus funciones de IA rotas desde antes de hoy.

GitHub justificó el cierre señalando que el salto de calidad en los modelos y en las herramientas de codificación agéntica volvió innecesario un editor separado: la misma experiencia de "describir y construir" ahora se puede lograr con GitHub Copilot dentro de VS Code, la CLI de Copilot o la app de Copilot, que además sí permiten desplegar a infraestructura propia en lugar de depender de un hosting cerrado como el de Spark.
