Google estrena Gemini 4 Hydrogen y Claude Code prueba un Code Mode, mientras Nvidia cambia de CEO y una caída global de Microsoft tumba Copilot

Un jueves con dos caras: del lado del desarrollador llegan un modelo rápido y barato de Google, un modo experimental de Claude Code y un respiro para quienes usan modelos de OpenAI en Cursor.
