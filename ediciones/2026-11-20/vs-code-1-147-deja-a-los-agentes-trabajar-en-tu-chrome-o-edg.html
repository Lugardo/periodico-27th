VS Code 1.147 deja a los agentes trabajar en tu Chrome o Edge y agrega Send Later

La versión de noviembre suma Browser Use en preview con tu navegador por defecto, routers de modelos, solicitudes de chat programadas y una política empresarial para permitir los harnesses de Claude y Codex.

Microsoft publicó Visual Studio Code 1.147 con varias novedades orientadas a agentes. La principal es Browser Use en preview: en lugar de limitarse al navegador integrado, los agentes pueden operar dentro de tu propio Google Chrome o Microsoft Edge cuando uno de ellos es el navegador por defecto, lo que permite probar flujos con tus sesiones y extensiones reales.

También llega Send Later, para programar solicitudes de chat que se ejecutan más tarde. Tiene una restricción importante: solo funciona con sesiones en This Computer y requiere que el host local del agente esté corriendo a la hora programada. Según el resumen del release, se añaden además routers de modelos definidos en YAML que eligen qué modelo atiende cada petición.

Para administradores aparece la política vscode.allowedHarnesses, que permite autorizar explícitamente los harnesses de Claude y Codex dentro del editor. La versión también anuncia la deprecación de la app de escritorio en macOS Ventura y Sonoma y en Linux ARM de 32 bits, algo a considerar si tu equipo o tus runners usan esas plataformas.
