Claude Code publica 2.1.328 y 2.1.329: auto mode para Opus 4.6 y Sonnet 4.6 en nubes de terceros y /tasks más completo

Dos versiones el mismo día traen auto mode en Bedrock, Agent Platform y Foundry, hooks que bloquean si fallan, cambios en /code-review y avisos sobre dónde se declaran los hooks de un proyecto.

Anthropic liberó el 19 de noviembre dos versiones seguidas de Claude Code. La 2.1.328 habilita auto mode para Claude Opus 4.6 y Sonnet 4.6 cuando se usan a través de Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry y el gateway de Claude apps; las sesiones interactivas sin modo de permisos explícito arrancan en él. También agrega la opción "onFailure": "block" a los hooks de tipo mcp_tool, para que una llamada fallida detenga la acción en lugar de dejarla pasar, y reorganiza /code-review: ahora reporta solo bugs y violaciones de CLAUDE.md, clasifica cada hallazgo como Important, Pre-existing o Nit, y deja las limpiezas de estilo a /simplify.

La 2.1.329 se enfoca en visibilidad y seguridad. El diálogo de confianza de una carpeta ahora indica dónde están declarados sus hooks, y /tasks muestra en un solo lugar las tareas programadas de la sesión, los wakeups de /loop, el goal activo y los forks de la conversación. En /mcp aparece el mensaje de error JSON-RPC cuando un servidor MCP remoto rechaza la conexión, y /code-review sin argumentos revisa toda la rama contra la rama por defecto. Además, Code Mode ya puede convivir con eventos y métricas de OpenTelemetry.

Hay cambios que conviene revisar antes de actualizar: varias tareas programadas guardadas con versiones anteriores deben volver a agendarse en sesiones nuevas, se eliminó el reintento automático ante errores de max_tokens (detrás de un gateway con límite menor hay que fijar CLAUDE_CODE_MAX_OUTPUT_TOKENS) y computer use en macOS adopta reglas de seguridad más estrictas. Entre ambas versiones suman más de 180 correcciones de bugs.
