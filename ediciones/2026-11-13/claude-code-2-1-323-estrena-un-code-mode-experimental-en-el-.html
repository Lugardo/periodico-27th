Claude Code 2.1.323 estrena un Code Mode experimental en el que Claude programa sus propias llamadas a herramientas

La nueva versión del CLI permite, de forma opcional, que Claude escriba JavaScript para invocar herramientas, y trae control de versiones para plugins y varias correcciones de permisos.

Anthropic publicó el 12 de noviembre la versión 2.1.323 de Claude Code. La novedad principal es Code Mode, una función experimental y opt-in en la que, en lugar de emitir llamadas a herramientas una por una, Claude genera código JavaScript que las invoca. La documentación está en la sección code-mode del sitio de Claude Code.

Para quienes distribuyen plugins, el archivo plugin.json acepta ahora un campo engines["claude-code"] para declarar con qué rango de versiones es compatible. Además, claude plugin validate revisa los tipos de los hooks escritos en TypeScript y, con --strict, falla ante cualquier advertencia.

La versión suma variables de entorno como CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES, para apagar los resúmenes de progreso de subagentes, y corrige huecos en reglas de Bash, el sandbox y rutas de Write/Edit bajo reglas de denegación de lectura. También cambia el comportamiento de --permission-mode auto: si el modo automático no está disponible, la sesión arranca en modo manual.
