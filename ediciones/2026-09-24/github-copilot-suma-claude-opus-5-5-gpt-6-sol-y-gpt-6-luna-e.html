GitHub Copilot suma Claude Opus 5.5, GPT-6 Sol y GPT-6 Luna el mismo día de sus lanzamientos

Los tres modelos nuevos ya están disponibles como opción en Copilot, junto con más controles para configurar las revisiones de código automáticas.

GitHub incorporó a Copilot, el mismo día de su anuncio, los tres modelos de frontera lanzados esta semana: Claude Opus 5.5 (4/20 dólares por millón de tokens de entrada/salida), GPT-6 Sol (2/10 dólares) y GPT-6 Luna (0.10/0.50 dólares), todos facturados según el precio de lista del proveedor bajo el esquema de uso medido. Opus 5.5 queda disponible para codificación agéntica, tareas largas y trabajo de conocimiento, y GitHub destaca que en pruebas tempranas resolvió tareas con menos pasos y tokens que Opus 5.

En paralelo, GitHub amplió las opciones de configuración de Copilot Code Review: ahora hay una página de configuración personal para activar la revisión automática y definir el nivel de esfuerzo de revisión por defecto, además de un ajuste a nivel empresa para repositorios de una organización, disponible de forma general.

Los nuevos modelos llegan a los planes Pro+, Max, Business y Enterprise de Copilot, consolidando la plataforma como uno de los primeros lugares donde los desarrolladores pueden comparar los tres modelos de frontera recién lanzados en un mismo flujo de trabajo.
