Agentic coding

Solana Playground integra un agente de IA para programar smart contracts desde el navegador

El IDE web de Solana, ahora en playground.solana.com, suma un agente conversacional que explica y edita código en proyectos Anchor o Rust nativo, sin instalar nada localmente.

Solana renovó su Playground, el IDE en el navegador que operaba como beta desde finales de 2022, y lo movió a un dominio oficial con un agente de IA integrado. Al crear un proyecto se elige entre Anchor o desarrollo nativo de Solana, y desde una interfaz conversacional se le piden al agente explicaciones del código existente o cambios concretos.

El enfoque declarado es de asistencia: el agente acompaña la edición y la comprensión del programa, más que generar aplicaciones completas de forma autónoma. Todo ocurre en el navegador, incluyendo compilar y desplegar, lo que baja la barrera de entrada para quien quiere experimentar con programas on-chain sin montar la toolchain de Rust.

La cobertura señala huecos importantes: no se ha dicho qué modelo usa el agente, si tendrá costo ni cómo se trata el código que se le envía. Conviene tenerlo presente antes de pegar código propietario en la herramienta.
