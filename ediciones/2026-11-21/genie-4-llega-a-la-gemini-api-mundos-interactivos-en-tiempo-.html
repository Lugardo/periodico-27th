Genie 4 llega a la Gemini API: mundos interactivos en tiempo real que se controlan desde código

Google habilitó su world model Genie 4 en la Gemini API y AI Studio para cuentas de pago, con streaming de mundos navegables a 720p con audio nativo.

Google puso Genie 4 a disposición de desarrolladores a través de la Interactions API de Gemini y de Google AI Studio. Es la primera vez que la compañía ofrece un world model como bloque de construcción para terceros: una app puede generar un mundo a partir de un prompt de texto, una imagen de referencia o ambos, y después dirigirlo en vivo con controles tipo teclado y nuevas instrucciones de texto.

La salida se transmite a 720p y 24 fps con audio generado por el propio modelo. Para conectarse hay WebRTC desde el navegador y WebSocket desde Python o Node.js, usando tokens efímeros emitidos por el backend de la aplicación. El modelo se invoca como models/genie-4 y requiere una API key del tier de pago.

Un detalle operativo importante: cerrar la conexión no detiene la facturación, así que la app debe llamar explícitamente a complete() para terminar la sesión. La cobertura reporta un costo cercano a 0.10 dólares por segundo de mundo generado y bloqueos para prompts con personas reales o propiedad intelectual de marcas; conviene revisar la documentación oficial antes de presupuestar, porque los límites de duración de sesión varían entre fuentes.
