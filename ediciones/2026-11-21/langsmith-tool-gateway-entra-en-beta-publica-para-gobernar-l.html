LangSmith Tool Gateway entra en beta pública para gobernar las llamadas a herramientas de los agentes

LangChain lanzó una capa administrada entre agentes y servidores MCP con credenciales centralizadas, políticas de bloqueo o aprobación y trazas de cada llamada.

LangChain abrió en beta pública Tool Gateway, un componente de LangSmith que se coloca entre los agentes y los servidores MCP que consumen. Complementa al LLM Gateway que la empresa ya ofrecía para llamadas a modelos: aquí lo que se controla es qué herramientas puede invocar un agente, con qué credenciales y bajo qué reglas.

Las políticas permiten bloquear llamadas que coincidan con ciertos criterios o exigir aprobación humana antes de ejecutarlas, y cada invocación queda registrada como traza; los clientes Enterprise reciben además un log de auditoría a nivel organización. Incluye servidores integrados para Google, Microsoft, Salesforce, GitHub y Linear, y funciona con clientes MCP como Claude Code y Cursor, además del propio ecosistema de LangChain.

Está disponible en los planes Plus y Enterprise de LangSmith Cloud en varias regiones de GCP y AWS (no en Azure US), con un límite documentado de 100 solicitudes por segundo y ráfagas de hasta 1,000.
