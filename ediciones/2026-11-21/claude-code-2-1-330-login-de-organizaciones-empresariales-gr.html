Claude Code 2.1.330: login de organizaciones empresariales, gráficas automáticas con easel y una larga lista de fixes

La nueva versión permite iniciar sesión en organizaciones administradas desde el Enterprise Admin Console y agrega easel, un mod integrado que dibuja gráficas.

Anthropic publicó la versión 2.1.330 de Claude Code. Tras `claude auth login`, la herramienta ahora aplica automáticamente la configuración de organizaciones gestionadas en el Enterprise Admin Console, incluido el proveedor de nube o gateway que la organización tenga definido. También se añadió easel, un mod incorporado que genera gráficas cuando se le piden y bajo resultados de métricas de MCP, disponible en Pro y Max (y en Team y Enterprise donde aplique) en macOS y Linux; se puede desactivar desde /config.

Para quienes operan runners autohospedados llegan `--start-dir` para arrancar el trabajo en una subcarpeta del repositorio y dos métricas nuevas en /metrics que miden el tiempo desde la orden de trabajo hasta el registro del runner y hasta la primera sesión.

El resto del release es mantenimiento de peso: se corrigen congelamientos tras compactar conversaciones muy largas, cuelgues de WebFetch, la pérdida de ajustes cuando varios procesos guardan a la vez, un caso en que salir de un worktree borraba uno que otra sesión estaba usando, y varios problemas de Code Mode, MCP y LSP.
