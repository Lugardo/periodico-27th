Agentic coding

Claude Code suma en dos días variable para el modelo por defecto, notificaciones entre sesiones y un modo 'Concise'

Las versiones 2.1.236 y 2.1.237 de Claude Code traen ANTHROPIC_DEFAULT_MODEL, avisos opt-in entre sesiones en la misma máquina y un estilo de salida que va directo a los resultados.

Anthropic publicó dos versiones consecutivas de Claude Code esta semana. La 2.1.236, del 19 de agosto, añade la variable de entorno ANTHROPIC_DEFAULT_MODEL para fijar con qué modelo arranca una sesión nueva sin que eso choque con una elección manual hecha con /model, que sigue teniendo prioridad y persiste entre reinicios. También suma notify_when_idle, una opción para que una sesión de Claude Code le pida a otra sesión en la misma máquina que le avise una sola vez cuando quede libre, sin necesidad de sondear el estado manualmente.

Esa misma versión endurece el sandbox en macOS: las reglas de denegación de lectura con comodines -como bloquear cualquier archivo .env- ahora tienen prioridad incluso dentro de directorios permitidos, cubren el contenido completo de esos directorios y no se pueden sortear renombrando el archivo bloqueado.

Un día después, la versión 2.1.237 corrigió un problema de cacheo de prompts para quienes usan Claude Code a través de un gateway de LLM o una URL base personalizada, y agregó un nuevo estilo de salida llamado 'Concise', configurable desde /config, en el que Claude va directo a los resultados sin preámbulos ni narración de lo que está haciendo, aunque mantiene el mismo nivel de trabajo.

Son cambios pequeños pero relevantes para quienes ya integran Claude Code en flujos de trabajo con proxies corporativos o múltiples sesiones simultáneas.
