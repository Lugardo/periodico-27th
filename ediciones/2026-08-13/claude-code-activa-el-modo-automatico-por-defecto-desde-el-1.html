Agentic coding

Claude Code activa el modo automático por defecto desde el 14 de agosto

En los planes Pro, Max y Team, Claude Code arrancará en "modo automático": un clasificador separado aprobará la mayoría de las acciones sin pedir confirmación manual en cada paso.

Para las sesiones nuevas de Claude Code, Anthropic activa el modo automático como comportamiento por defecto en los planes Pro, Max y Team a partir del 14 de agosto. En lugar de pedir aprobación manual para cada comando de shell o cambio de archivo, un modelo clasificador independiente revisa cada acción antes de ejecutarla y bloquea las que se salen del pedido original, tocan infraestructura no reconocida o parecen inducidas por contenido hostil que Claude leyó en el camino.

La justificación que da la empresa se apoya en un estudio interno: frente a un comando peligroso plantado a propósito, los revisores humanos lo detectaron solo el 13.6% de las veces, contra el 89% del clasificador automático. Quienes ya tengan configurado otro modo por defecto van a recibir un aviso único preguntando si quieren cambiarse a automático; los defaults fijados por un administrador vía managed settings quedan intactos.

Para quien usa Claude Code a diario esto cambia el flujo de trabajo de forma directa: menos interrupciones para aprobar comandos rutinarios, pero también menos control manual explícito sobre cada paso. Anthropic dice que el costo de tokens del propio clasificador no se descuenta del uso del plan. Vale la pena revisar la configuración de permisos antes del 14 de agosto si se prefiere mantener el modo manual.
