GitHub Copilot suma Gemini 4 Hydrogen y lleva su app a GitHub Enterprise Server

Hydrogen ya está disponible de forma general en Copilot con facturación por uso, la app de Copilot soporta oficialmente GHES desde la versión 1.2.0 y Copilot CLI llegó a la 1.0.111.

Un día después de su presentación, Gemini 4 Hydrogen, el modelo rápido de Google orientado a trabajo de agentes, quedó disponible de forma general en GitHub Copilot. Se cobra al precio de lista del proveedor dentro del esquema de facturación por uso.

En paralelo, el soporte para GitHub Enterprise Server dentro de la app de GitHub Copilot pasó de preview opcional a disponibilidad general a partir de la versión 1.2.0. Hay una limitación importante: las sesiones en la nube no están disponibles para instancias GHES, así que los equipos on-premise trabajan solo con ejecución local.

Además, Copilot CLI publicó la versión 1.0.111, que agrega soporte de expresiones regulares en las reglas de permisos de shell administradas por la empresa y una nueva opción `--host-allow-session-creation`. Son cambios menores, pero útiles para administradores que necesitan acotar qué comandos puede ejecutar el agente.
