OpenAI lanza un plugin de administración para ChatGPT Work y Codex

El nuevo Admin plugin deja a los administradores de espacios de trabajo gestionar miembros, permisos y límites de uso desde una sola conversación con ChatGPT.

OpenAI presentó el Admin plugin para ChatGPT Work y Codex, disponible desde el directorio de plugins de ChatGPT Work. La idea es que un administrador pueda hacer una pregunta, revisar el detalle y aplicar un cambio autorizado sin salir de la conversación ni cambiar entre paneles distintos.

Entre las tareas que cubre están: revisar adopción y uso de créditos por miembro o grupo, dar de alta o baja usuarios y actualizar grupos, controlar el acceso a modelos o funciones por rol, y aprobar o rechazar solicitudes de aumento de límite de gasto con contexto de uso actual.

Para equipos de desarrollo que ya usan Codex dentro de un plan Work, el plugin reduce la fricción operativa de administrar accesos y cuotas, algo que hasta ahora requería entrar al panel web de administración por separado.
