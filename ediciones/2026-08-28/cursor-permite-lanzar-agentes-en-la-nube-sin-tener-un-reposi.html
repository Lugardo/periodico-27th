Agentic coding

Cursor permite lanzar agentes en la nube sin tener un repositorio conectado

Los Cloud Agents de Cursor ya no requieren GitHub ni otro proveedor de control de versiones para arrancar: basta con elegir 'Start from scratch' y describir la tarea al agente.

Cursor actualizó el 27 de agosto sus Cloud Agents para eliminar un paso de fricción habitual: hasta ahora, para lanzar un agente en la nube era obligatorio conectar primero un repositorio de GitHub u otro proveedor. Con el cambio, basta con seleccionar 'Start from scratch' en el selector de repositorios y darle el prompt al agente directamente.

En segundo plano, Cursor crea automáticamente un repositorio propio (un 'Origin repo') donde el agente va guardando el avance del proyecto. Una vez que el resultado del agente satisface al usuario, este puede pulsar 'Create repo' para conservar el trabajo en un repositorio con nombre propio, ya sea uno sugerido por la herramienta o uno personalizado.

El cambio apunta a bajar la barrera de entrada para prototipar rápido: en vez de crear primero un repo vacío en GitHub y luego pedirle al agente que trabaje sobre él, el flujo se invierte y el repositorio se vuelve un artefacto que se genera después, solo si el resultado vale la pena conservarlo.
